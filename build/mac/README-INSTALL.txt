Transcribator — установка на macOS
=================================

Приложение собрано без подписи Apple Developer, поэтому macOS может
показать: «приложение повреждено». Это карантин Gatekeeper, а не
реальная порча файла.

Вариант A (рекомендуется) — PKG
-------------------------------
Установите Transcribator-*.pkg. После установки карантин снимается
автоматически (скрипт postinstall).

Вариант B — DMG, одной командой
-------------------------------
1. Откройте DMG.
2. Дважды щёлкните «Install Transcribator.command»
   (подтвердите доступ, если спросит).
3. Приложение скопируется в /Applications и карантин снимется само.

Вариант C — вручную
-------------------
1. Перетащите Transcribator.app в папку «Программы» (/Applications).
2. В Терминале выполните:

   xattr -cr /Applications/Transcribator.app

3. Запустите Transcribator из «Программ».

Если macOS всё ещё блокирует запуск: правый клик по приложению →
«Открыть» → подтвердите, либо Системные настройки →
Конфиденциальность и безопасность → «Всё равно открыть».

Для глобального перехвата клавиатуры нужен доступ Accessibility
(Системные настройки → Конфиденциальность и безопасность → Универсальный доступ).
