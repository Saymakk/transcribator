# Transcribator

Кроссплатформенное приложение (Windows / macOS / Linux) для глобальной транслитерации, Punto-переключения раскладки и текстовых утилит. Работает в системном трее.

## Разделы

- **Раскладки** — правила и палитра (в т.ч. глаголица и корейский); поля ввода работают как в обычном редакторе (Ctrl+C/V/X/A/Z)
- **Конвертер** — вставка текста / загрузка и drag-and-drop документов (PDF, Word, ODT, RTF, EPUB, FB2, Excel, ODS, PPTX, HTML, Markdown, CSV и др.), перегон только букв по активной раскладке
- **Punto** — QWERTY ↔ ЙЦУКЕН (живой режим и ручная конвертация)
- **Текст** — регистр, snake/kebab/camel и обрамление строк
- **Настройки** — язык, автозапуск, горячие клавиши, проверка обновлений

Переключение разделов **не отключает** активные режимы. В боковой панели всегда видна полоса режимов (Транслит / Punto).

Язык интерфейса: **Русский, English, Українська, Deutsch, Français, Español, Polski, 中文, 한국어, العربية** (раздел «Настройки»).

## Аккорды и режимы

| Действие | Как |
|----------|-----|
| Прямой транслит | `Ctrl`+`A`+`D` или кнопка «Прямо» (настраивается) |
| Обратный транслит | `Ctrl`+`D`+`A` или кнопка «Обратно» |
| Punto EN→RU / RU→EN | кнопки в полосе режимов или раздел Punto |
| Отмена последней замены | двойное быстрое нажатие `Ctrl` (настраивается) |

В разделе **Punto** выберите **языковую пару** (по умолчанию Русский ↔ English), затем направление (например EN→RU). Словарь пары подключается автоматически; свой словарь дополняет его.

При активном транслите он имеет приоритет; двойной Ctrl отменяет и транслит-, и punto-замену. Пока открыто окно настроек, глобальная автозамена и аккорды не мешают обычному редактированию полей.

## Платформы и обновления

Один Electron-проект собирается в установщики:

| ОС | Артефакт | Хук клавиатуры |
|----|----------|----------------|
| Windows | NSIS `.exe` | обычно без доп. прав |
| macOS | `.dmg` + `.zip` (для автообновления) | нужен Accessibility |
| Linux | AppImage, `.deb` | надёжнее на X11 |

Обновления **не компилируют исходники** и **не качают распакованный проект**. Приложение скачивает готовый установщик (`electron-updater`). С blockmap качаются только изменившиеся куски файла, а не все 100+ МБ.

**Откуда брать обновление** (Настройки → Обновления):

1. **GitHub Releases** (по умолчанию) — репозиторий уже прописан: [Saymakk/transcribator](https://github.com/Saymakk/transcribator).
   1. Репозиторий должен быть **публичным** (иначе приложение не скачает файлы без токена).
   2. Закоммитьте и запушьте код вместе с `.github/workflows/release.yml`.
   3. Поднимите `version` в `package.json` (например `1.0.1`) — она должна быть **выше**, чем у уже установленных пользователей.
   4. Создайте и отправьте тег той же версии:
      ```bash
      git add -A
      git commit -m "Release 1.0.1"
      git tag v1.0.1
      git push origin master
      git push origin v1.0.3
      ```
   5. В GitHub: **Actions** → workflow **Release** должен собрать Windows/macOS/Linux и залить файлы в [Releases](https://github.com/Saymakk/transcribator/releases). Нужны `Transcribator Setup …exe`, `latest.yml` и `.blockmap`.
   6. В установленном приложении: **Настройки → Обновления → GitHub Releases → Проверить обновления**.

   Локально (без Actions), с [PAT](https://github.com/settings/tokens) права `repo`:
   ```bash
   set GH_TOKEN=ghp_...
   npm run build
   npx electron-builder --win --publish always
   ```
2. **Яндекс Диск / HTTPS-папка** — после `npm run dist:win` в `release/` появятся:
   - `latest.yml`
   - `Transcribator Setup x.y.z.exe`
   - `Transcribator Setup x.y.z.exe.blockmap`
   
   Залейте все три файла в **публичную папку** Яндекс Диска (или на любой хостинг с прямой ссылкой) и вставьте ссылку на папку в настройках.

**Google Диск** для установщика не подходит: ссылка «доступ по ссылке» отдаёт HTML-страницу проверки на вирусы, а не файл. Для большого `.exe` обновлятор его не скачает.

В приложении: **Настройки → Проверить обновления**.

Поддержать: кнопка **Донат** у названия → [Liberapay](https://liberapay.com/Saymakk/donate) / [Ko-fi](https://ko-fi.com/saymakk).

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run dist:win` / `dist:mac` / `dist:linux`

## Права

- **macOS** — Accessibility для глобального хука
- **Linux** — надёжнее на X11
- **Windows** — обычно без доп. прав (кроме elevated-приложений)
