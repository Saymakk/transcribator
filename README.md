# Transcribator

Кроссплатформенное приложение (Windows / macOS / Linux) для глобальной транслитерации, Punto-переключения раскладки и текстовых утилит. Работает в системном трее.

## Разделы

- **Раскладки** — правила и палитра (в т.ч. глаголица и корейский); поля ввода работают как в обычном редакторе (Ctrl+C/V/X/A/Z)
- **Конвертер** — вставка текста / загрузка и drag-and-drop документов (PDF, Word, ODT, RTF, EPUB, FB2, Excel, ODS, PPTX, HTML, Markdown, CSV и др.), перегон только букв по активной раскладке
- **Punto** — QWERTY ↔ ЙЦУКЕН (живой режим и ручная конвертация)
- **Текст** — регистр, snake/kebab/camel и обрамление строк

Переключение разделов **не отключает** активные режимы. В боковой панели всегда видна полоса режимов (Транслит / Punto).

Язык интерфейса: **Русский, English, Українська, Deutsch, Français, Español, Polski, 中文, 한국어, العربية** (выбор в разделе «Статус»).

## Аккорды и режимы

| Действие | Как |
|----------|-----|
| Прямой транслит | `Ctrl`+`A`+`D` или кнопка «Прямо» |
| Обратный транслит | `Ctrl`+`D`+`A` или кнопка «Обратно» |
| Punto EN→RU / RU→EN | кнопки в полосе режимов или раздел Punto |
| Отмена последней замены | двойное быстрое нажатие `Ctrl` (≤0.4 с) |

В разделе **Punto** выберите **языковую пару** (по умолчанию Русский ↔ English), затем направление (например EN→RU). Словарь пары подключается автоматически; свой словарь дополняет его.

При активном транслите он имеет приоритет; двойной Ctrl отменяет и транслит-, и punto-замену. Пока открыто окно настроек, глобальная автозамена и аккорды не мешают обычному редактированию полей.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run dist:win` / `dist:mac` / `dist:linux`

## Права

- **macOS** — Accessibility для глобального хука
- **Linux** — надёжнее на X11
- **Windows** — обычно без доп. прав (кроме elevated-приложений)
